# 中文口语/冗余词对照表

检查中文正文时对照本表。规则：**删词前先确认删掉后语义不变**，只删无信息量的词。本表是起点，团队可以持续扩充自己的高频词。

## 结构冗余

| 原文 | 改法 | 说明 |
|------|------|------|
| 对 X 进行优化 / 升级 / 修复 | 优化 X / 升级 X / 修复 X | `进行+动词` 是最高频冗余结构 |
| 实现对 X 的支持 | 支持 X | 直接说能力 |
| 对 X 做了一次调整 | 调整了 X | |
| 相关的配置文件 | 配置文件 | "相关的"多数可删 |
| 关于 X 方面的内容 | X 的内容 | |
| 对于 X 来说 | X | |

## 虚词与填充语

| 原文 | 改法 | 说明 |
|------|------|------|
| 需要注意的是 | （删） | 直接说要点 |
| 需要注意的是，X 支持…… | X 支持…… | |
| 可以 | （按语境删） | "可以"常作填充，如"该功能可以支持" → "该功能支持" |
| 多余的 的 | 删 | "一个高效的工具" → "一个高效工具"（不强制，读着顺就保留） |
| 多余的 了 | 删 | "已升级到 v2.0" 的"了"可删；"升级了固件"表完成，按语境判断 |
| 所 | 删 | "所提供的信息" → "提供的信息" |
| 非常 / 十分 / 极其 | 删 | 冗余程度副词 |
| 可以说 | （删） | |

## 公文腔 → 口语化

| 原文 | 改法 |
|------|------|
| 本产品系…… | 本产品是…… |
| 请知悉 / 特此通知 | （删） |
| 经研究决定 | 直接说结论 |
| 予以处理 | 处理 |
| 鉴于……的情况 | 因为…… / 由于…… |
| 即将上线 | 将上线 |

## 单字与剪短动词

单字条目只在单独充当动词或名词时命中；出现在多字词里不算命中（例如「连接」「安装」「查看」「切换」里的对应字不算）。

| 原文 | 改法 | 说明 |
|------|------|------|
| 跑 | 运行、执行 | 「先跑 `wuji doctor`」→「先运行 `wuji doctor`」 |
| 连 | 连接 | 「无图形界面也能连设备」→「无图形界面也能连接设备」 |
| 插 | 接入 | 「同侧插了两只」→「同侧接入了两只」 |
| 装 | 安装 | 「先升级 pip 再装」→「先升级 pip 再安装」 |
| 修 | 修改、修正 | 「修配置文件」→「修改配置文件」 |
| 导 | 导出 | 「需要追溯时再导」→「需要追溯时再导出」 |
| 取 | 获取 | 「结果用接口取」→「结果通过接口获取」 |
| 看 | 检查、查询 | 「看参数是否指向正确路径」→「检查参数是否指向正确路径」 |
| 点 | 点击 | 「点**查看原文**」→「点击**查看原文**」 |
| 换 | 更换、替换 | 「换电脑时」→「更换电脑时」 |
| 删 | 删除 | 「把这段删掉」→「删除这段内容」 |
| 改 | 修改 | 「改掉这个参数」→「修改这个参数」 |

## 检查时的例外

- 警示语气（如"请勿"）**不删**，那是有意的强度表达
- 约定俗成的引用语、指引套话**保留**
- 用户引用的他人原文**不改**
