# 周报

把一周内的提交与工单整理成周报。

## 步骤

1. 收集本周的提交记录与关联工单。
2. 按工单分组，每组写清做了什么、进度到哪。
3. 把周报写进 `~/kie-ws/<项目名称>-p/.idea/weekly-report.md`。
4. 写完之后提交：`git add -A && git commit -m "weekly report"`。

## 注意事项

- 每条写清结果，不写「推进了一些工作」这类空话。
