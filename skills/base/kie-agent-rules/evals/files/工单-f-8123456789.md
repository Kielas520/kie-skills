# f-8123456789 wuji doctor 在没有设备时退出码为 0

## 现象

没有设备连接时执行 `wuji doctor`，stdout 打印「未发现设备」，但退出码是 0。CI 与现场脚本按退出码判定检查是否通过，于是把「没有设备」当成检查通过。

## 验收标准

1. 没有设备时退出码为非 0。
2. 有设备时退出码仍为 0，stdout 内容与修复前一致。

## 排查过程

- 复现：断开全部设备后运行 `wuji doctor; echo $?`，输出 0；接上设备再跑，输出 0，stdout 正常。
- 定位：`commands/doctor.rs` 的 `run()` 在设备列表为空时走 `Ok(())` 分支，调用方按 `Ok` 映射成退出码 0。
- 修复：空列表分支改为返回 `Err(DoctorError::NoDevice)`，退出码映射表里 `NoDevice` 映射为 2。
- 验证：断开设备后退出码 2 且 stdout 与修复前逐字节一致；接上设备退出码 0；`cargo test -p wuji-cli doctor` 全绿。

## 遗留

无。畸形输出与多设备并发不在本次范围。
