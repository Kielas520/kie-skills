# 会议纪要归档

## 步骤

1. 读取用户给的纪要原文。
2. 按会议日期在 `notes/<YYYY-MM-DD>.md` 归档，文件已存在时在末尾追加。
3. 每个议题一个二级标题，标题下列结论与待办，待办写明负责人。

## Gotchas

- 纪要里没写负责人的待办，标成「负责人待定」，不自行指定。
- 归挡前先确认日期，纪要里没写日期时问用户。
