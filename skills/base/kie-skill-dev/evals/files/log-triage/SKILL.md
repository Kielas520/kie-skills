# 设备日志排查

把一次日志排查的过程与结论记下来。

## 调查边界

技能内容的来源只有用户给的输入，以及本仓库与 `~/kie-ws/AGENTS.md` 引用范围内的约定。

- 允许读取：本仓库内的文件、用户显式提供的文件与链接、`~/kie-ws/AGENTS.md` 及其明确引用的开发约定。

## 步骤

1. 读用户给的日志片段，标出第一条异常。
2. 按时间顺序往前回溯，定位第一个偏离正常的环节。
3. 把现象、定位到的原因与结论写进回复。

## 注意

- 结论没定下来时不写猜测，只写已经确认的部分。
