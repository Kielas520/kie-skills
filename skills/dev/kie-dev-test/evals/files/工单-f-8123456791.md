# f-8123456791 devctl 读取固件版本时多出前缀

## 问题描述

`devctl.py version` 通过串口向设备查询固件版本，设备回复 `VER 2.4.1`。v0.2.0 把整行原样打印成 `VER 2.4.1`，下游脚本按纯版本号解析时报错。

- 发现版本：v0.2.0
- 环境：Ubuntu 26.04，设备通过 USB 串口接入（`/dev/ttyUSB0`）
- 复现步骤：接上设备，执行 `python3 devctl.py version`

## 验收标准

1. 接上真实设备执行 `python3 devctl.py version`，只输出版本号本身（如 `2.4.1`），不带 `VER ` 前缀。
2. 设备回复格式不对时，命令以非零退出码结束并给出可读的错误信息，不打印半截版本号。
