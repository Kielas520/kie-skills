# f-8123456790 logfmt 解析含空行的日志时多出一条空记录

## 问题描述

`logfmt` 解析含空行的日志文件时，结果里会多出一条 level 与 message 都空的记录，输出条数与有效行数对不上，下游按条数对账时对不上。

- 发现版本：v0.1.0
- 复现步骤：在 `source/demo` 下执行 `cargo run -q -p cli -- sample.log`，sample.log 第 3 行为空行，输出 5 条记录，有效行只有 4 行
- 期望：空行与结尾换行不影响解析，条数与有效行数一致，其余字段内容不变

## 验收标准

1. 含空行与结尾换行的日志文件能完整解析，输出条数与有效行数一致，结果里没有空记录。
2. 去掉空行后解析出的字段内容与 v0.1.0 在同样输入上的结果完全一致。

## 环境

Rust 1.80 及以上，Linux。有问题那一版的源码在 `source/logfmt-0.1.0/`。
