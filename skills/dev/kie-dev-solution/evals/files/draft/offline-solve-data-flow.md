# 离线解算数据链路（草稿）

> 关联工单：m-7000000001

本文说明离线解算用到哪些资源、暴露哪些接口、数据如何流动，源码位置以仓库根为基准。

## 离线解算的边界

不连设备、不建立订阅，由调用方把已经录下来的帧逐帧传进 SDK，同步取回解算结果。它与实时链路共用同一套求解器，差别只在帧的来源。

| 类别 | 链路 |
| --- | --- |
| 覆盖 | `EmfPoseArray` → 关节角、指尖位姿、手部骨架（一次解算同时出三件） |
| 覆盖 | raw `ImuData` → 融合 `ImuData`，6 条独立支链 |
| 不覆盖 | EMF 原始数据到 `emf_poses` 这一段解算 |
| 不覆盖 | 触觉点云、坐标系变换 |

## 实时链路与离线链路的对应

实时链路：`emf_raw_data` → `emf_poses` → `hand_joint_angles` → `tip_poses` / `hand_skeleton`；`imu_raw/<指>` → `imu_data/<指>`。

离线把中间产物当入口：调用方给 `EmfPoseArray`，等价于给 `emf_poses` 的输出。
