## 分支简述

问题：含空行的日志文件解析后会多出一个空对象，条数与有效行数不一致。

解决方案：解析时跳过空白行，保持其余字段处理逻辑不变。

变更的内容：`logfmt.py` 的 `parse()` 增加空白行判断。

| 验收标准 | 结果 |
| --- | --- |

| 去掉空行后字段内容与 v0.1.0 一致 | 通过 |

缺陷对照实验：v0.1.0 复现多出空对象，当前分支确认问题不再出现。
