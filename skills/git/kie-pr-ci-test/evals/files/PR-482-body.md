## 问题

关联工作项：[f-8123456789](https://project.feishu.cn/example/issue/detail/8123456789)

`logfmt.py` 解析含空行的日志文件时多出一个空对象 `{}`，输出条数与有效行数不一致。发现版本 v0.1.0，`python3 logfmt.py sample.log` 输出 5 条记录，有效行只有 4 行。

## 原因

`parse()` 对每一行都构造一条记录，空白行经过 `strip()` 后留下空字段集合，仍被 append 进结果列表。

## 改动

`parse()` 在 `strip()` 之后跳过空白行，其余字段处理逻辑不变。

## 验证

同条件下 v0.1.0 输出 5 条记录且第 3 条为空对象，当前分支输出 4 条记录、无空对象。两条验收标准的验证方式与结果：

| 验收标准 | 结果 |
| --- | --- |
| 条数与有效行数一致，无空对象 | 通过 |
| 去掉空行后字段内容与 v0.1.0 一致 | 通过 |

实机 SN 与固件版本：不涉及实机。CI 链接待远端结果追加。
