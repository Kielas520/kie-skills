## 填写要求

1. 只替换报告里「远端 CI 结果」这一节，报告的其他章节（本地测试结果）不动。
2. 「远端产物验收结果」逐条对应工单验收标准，测试对象是下载下来的 CI 产物；序号与本地「测试结果」保持一致，便于对照。
3. 「远端对照实验」只在缺陷单填，不是缺陷单就删掉这一小节。
4. 远端产物跑不起来（缺少依赖、平台不符）的验收标准，以及没有真实设备而用 mock 代替的场景，都写进「远端未覆盖」，写明缺什么前提与影响；都覆盖到时写「无」。
