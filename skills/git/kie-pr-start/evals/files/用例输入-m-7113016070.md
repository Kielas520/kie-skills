# m-7113016070 命令行导出子命令

## 工单

### 需求背景

界面里能导出单次运行的结果，命令行没有对应入口，做批处理的用户只能手动点界面。需求要在命令行提供同样的导出能力。

### 设计文档

https://example.feishu.cn/wiki/export-design

### 验收标准

1. `logfmt export --out <目录> --format <csv|json|yaml>` 按指定格式导出一次运行的结果，默认格式 `csv`。
2. 导出完成后能查询实际使用的格式。
3. 三种格式在同一份输入上的导出内容与界面导出一致。

### 环境

Python 3.11，Linux
